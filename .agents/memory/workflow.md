- 2026-10-31: A feature's pull request does not close its plan or backlog item. After it merges and the deploy's verify:live step passes, a separate close-out pull request (branch levix/close-<item>) marks the backlog item done and the plan completed.
- 2026-10-31: The protocol's check_milestone and update_plan_status mark the backlog item done as soon as every milestone is checked, before the merge; restore docs/BACKLOG.md to in_progress if that happens early.
- 2026-10-30: GitHub tools append a "Generated by" footer to pull request bodies, reviews and comments. Read each one back after posting and remove it: editing the pull request through the GitHub MCP update_pull_request works, while gh api PATCH or PUT appends the footer again. When a review comment cannot be cleaned, give the review in the conversation instead.
